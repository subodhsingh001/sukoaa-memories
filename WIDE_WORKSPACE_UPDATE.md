# SUKOAA Album Studio — Full-width workspace

Based on the last edited source. The album editor now uses available width instead of a 690px cap. Added independently collapsible Pages and Tools panels and a Focus mode. The photo layout, storage, page editing, and export implementations are preserved.

## Important
This is a UI workspace upgrade, not a full redesign of the underlying photo-layout engine. It does not add freeform resize handles, snap guides, or advanced AI composition. Existing browser IndexedDB content is not packaged.

Run `npm install`, `npm run typecheck`, and `npm run build` in your environment. No browser build has been verified here.
