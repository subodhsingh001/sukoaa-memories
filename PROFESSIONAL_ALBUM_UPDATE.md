# Professional album update

- Home/dashboard is now the default screen, including for first-time visitors; welcome remains in source but does not block the dashboard.
- Removed the unreliable WebGL book from the album editing flow. The Book Preview button opens a reliable HTML/CSS two-page printed-book presentation with original IndexedDB photo URLs, spine, paper depth, and real images.
- The editor retains per-image repositioning, zoom, fit and photo replacement through the inspector.
- Added nine page compositions: Hero, Pair, Collage, Triptych, Mosaic, Seamless, Editorial, Filmstrip, Minimal, with selectable visual thumbnails.
- Album template cards now show an actual photograph where available.
- The existing print PDF workflow remains; confirm bleed and trim with the printing company.
- No physical print ordering, AI-driven layouts, or simulated paper bending is claimed.
- Dependencies were unavailable offline here, so a complete typecheck and build could not be verified. Run npm ci, npm run typecheck, npm run build on your machine.
